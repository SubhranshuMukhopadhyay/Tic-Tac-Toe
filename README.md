# Tic Tac Toe
The repository was build on the concept of a veery popular short game. Known as Tic Tac Toe.
There are two main pages in the repository. 
1. Home Page
2. Game Page
There is another page which is the 'Error Page'. All the pages are connected using 'React-Router'.
There is no separate CSS file has used for this project. The styling has been done inside the same JSX file using 'Tailwind CSS'.
